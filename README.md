This project provides a ROS 2 Foxy-based environment for simulating and controlling the DJI Tello drone inside Gazebo. It uses a foxy Docker to be able to simulate.
It is designed to make setup and deployment simple, portable, and reproducible for anyone.

This work is part of my thesis project, focusing on developing a drone capable of autonomously flying through colored rings in a simulated environment.
The system is built on Ubuntu and utilizes ROS 2 (Foxy) for communication and control, with the logic implemented in Python and enhanced by fuzzy logic for decision-making and adaptive behavior.
